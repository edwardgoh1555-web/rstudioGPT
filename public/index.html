Default Agent Prompt

Set the default instructions that will be pre-populated for the narrative generation agent. Users can modify these instructions for individual generations.

Qualification Criteria Prompt

Set the default qualification criteria prompt. This prompt is combined with the uploaded supporting documents to generate a qualification assessment Word document. Users can edit the prompt per-generation.

Value Case Prompt (Step 5)

Set the default value case prompt. This prompt structures the business case document that synthesises supporting evidence and qualification findings. The output is chunked and fed into the Provocation step. Users can edit per-generation.

Provocation Prompt (Step 6)

Set the default provocation prompt for "The Origination Engine" document. This prompt structures the strategic provocation with eight frameworks and forty-one diagnostic prompts. Users can edit per-generation.

C-Suite Review Prompts (Step 7)

Configure the default persona instructions for each C-suite reviewer. These prompts are appended to the review system prompt to give the AI a specific executive perspective when reviewing documents.
